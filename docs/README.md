# Documentation

All project documentation is indexed by responsibility:

- [Technology](technology/README.md) contains implemented contracts and mandatory engineering rules.
- `docs/user/` (project-specific, not included in this shared repo) contains user-provided requirements and
  optional scientific/domain references. `AI_INSTRUCTIONS.md` reviews it before any change, when present.

Documents under `technology` are normative according to their stated scope. User/domain references do
not describe planned or implemented functionality unless a separate product requirement adopts them.
