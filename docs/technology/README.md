# Technology

Normative documentation: mandatory engineering rules and implemented contracts. Everything here describes
present repository behavior or binding requirements, never planned work.

- [Compact technology rules](rules/README.md) — the complete concise ruleset every implementation must
  follow: architecture, domain/application design, code structure and cleanliness, build/testing/
  performance, documentation and acceptance, and the C++23/Rust low-level rules.

Add a project's own implemented-contract docs here too (e.g. a rendering pipeline or a build/distribution
writeup) — those belong in the consuming project, not in this shared repo.
